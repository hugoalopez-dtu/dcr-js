\section*{Use of Generative AI}
While preparing this thesis, GitHub Copilot, Claude (Anthropic, used
directly via Claude Code for agentic coding and data work), ChatGPT
(OpenAI), and Gemini (Google) were used to support my work, but in no
way replace it -- all thoughts, ideas, and conclusions presented in
this thesis are my own. These tools were used in the following ways:

\begin{itemize}
    \item \textbf{Coding and Scripting:} GitHub Copilot and Claude
    Code were used while implementing and debugging the Python
    scripts used for training, analysis, and figure generation
    throughout this thesis. I personally reviewed and verified every
    code suggestion before accepting it, and adjusted it where
    needed -- I have programmed regularly throughout my degree and
    this master's programme and am qualified to evaluate the output
    of these tools.

    \item \textbf{Data Verification:} Claude was used systematically
    to cross-check reported figures, tables, and claims against the
    underlying raw experiment logs before they were included in the
    text. This process caught several genuine inconsistencies between
    earlier drafts and the actual data, which were corrected as a
    result; it was a verification step, not a source of new claims.

    \item \textbf{Language, Structure, and Editorial Revision:} A mix
    of ChatGPT, Gemini, and Claude was used not only for sentence-level
    language suggestions, but, more substantially with Claude (via
    Claude Code), for restructuring dense or redundant passages:
    cutting content duplicated across chapters, reorganising
    paragraphs for clarity, and rewriting confusing explanations. In
    every case the underlying findings, data, and decisions about what
    the thesis argues were mine; the AI's role was to propose a
    clearer expression of content I had already established, and I
    reviewed and approved every resulting change before it entered the
    thesis. At no point was AI asked to invent a finding, fill an
    evidentiary gap, or decide what the thesis should claim.

    \item \textbf{Brainstorming:} ChatGPT, Gemini, and Claude were
    used to brainstorm ideas during various phases of the project,
    for instance when exploring alternative explanations for an
    experimental result before deciding which to investigate further.

    \item \textbf{\LaTeX{} Support:} The same tools were used to help
    fix \LaTeX{} errors and to assist with writing equations, tables,
    and figure layouts.

    \item \textbf{Search Engine:} AI tools were also used as a way to
    more quickly locate relevant search queries and sources than I
    could formulate alone. In every case, this only produced a list of
    candidate links or references, which I then reviewed myself.
\end{itemize}

On a general note, all outputs from any of the above tools have been
critically examined by me before serving as inspiration or input for
this report.

Lastly, I am fully responsible for the contents of this document.
